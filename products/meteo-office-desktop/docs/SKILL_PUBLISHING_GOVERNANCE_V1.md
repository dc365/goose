# MeteoMate Skill 发布治理 V1

## 目标

阶段 4 把当前登录用户、Skill Creator 草稿、SkillHub 发布记录和管理员代管能力连接成一个闭环：

```text
当前登录用户
    ↓ 用户专属 Skill 草稿
Skill Creator
    ↓ 上传不可变版本
SkillHub ownerId
    ↓ 发布、弃用、调整可见范围
我的发布 / 发布管理
```

## 用户入口

具有 `publisher` 或 `admin` 角色的用户在技能中心看到：

- `我的发布`：发布者只看到自己名下的 Skill；
- `发布管理`：管理员看到全部发布者的 Skill；
- 草稿、已发布和已弃用状态；
- 当前公开版本、可见范围、负责人和更新时间；
- 各版本的风险等级、包大小与版本说明。

普通使用者不显示发布管理入口。

## 生命周期

```text
本地草稿
  → 上传为 SkillHub 草稿版本
  → 发布并进行 Ed25519 签名
  → 保持不可变
  → 需要停止分发时标记为已弃用
```

已发布版本不能覆盖。内容修改必须更新 Skill Creator 草稿中的版本号并重新上传。

## 所有权与权限

- `ownerId` 使用 SkillHub 稳定用户 ID，不使用用户名或显示名称；
- 发布者只能管理自己拥有的 Skill；
- 管理员可以管理全部 Skill；
- 只有管理员可以转移所有权；
- 新负责人必须是启用中的发布者或管理员；
- 所有权转移同步更新发布者名称和组织范围；
- 组织可见 Skill 必须具有有效的组织 ID；
- 发布、弃用、资料修改和所有权转移写入审计日志。

## 与助理空间的关系

Skill Creator 草稿和用户级安装仍保存在当前账户的本机资料目录。切换用户后，桌面端会切换到该用户的 `MeteoMate/Claw/<profileKey>` 默认助理空间，不会读取另一账户的草稿、安装目录或任务状态。

SkillHub 只保存发布包、版本元数据、所有权与审计信息，不上传对话内容、项目文件或助理空间中的其他资料。

## 验收路径

1. 发布者登录并从 Skill Creator 上传草稿；
2. `我的发布` 显示草稿版本和当前负责人；
3. 发布者修改名称、摘要、分类、标签和可见范围；
4. 发布者确认发布，版本变为已发布并签名；
5. 发布者弃用版本，已安装副本不被删除；
6. 另一个发布者不能管理该 Skill；
7. 管理员把 Skill 转交给另一名启用中的发布者；
8. 新负责人可以继续上传新版本，原负责人失去管理权限；
9. 审计记录能够查询资料修改、发布、弃用和所有权转移。
