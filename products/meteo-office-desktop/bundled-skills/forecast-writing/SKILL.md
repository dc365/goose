# 气象预报写稿

## 规则

1. 写稿前校验资料时次、有效期、区域和结论状态。
2. 实况、预报、算法结果和推断必须使用不同表述。
3. 风险用语、地名、量级和时间范围遵循业务规范。
4. 正文结论必须与图表和 Evidence 一致。
5. 未通过发布门禁的内容只能标记为草稿。

## 推荐结构

- 标题与发布时间
- 天气形势
- 主要天气过程
- 重点区域与时段
- 风险提示
- 不确定性
- 数据与图件来源

## 验证

- [ ] 无虚构数据
- [ ] 数值和单位完整
- [ ] 图文一致
- [ ] 已标明草稿或签发状态
